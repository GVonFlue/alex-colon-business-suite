WHAT WAS STILL DIFFERENT, SIDE BY SIDE
--------------------------------------------------------------------------

Comparing the two screenshots, four things, and none of them were the parts I
had already ported:

1. NO PAGE SUBTITLE. ProyTech has one under every heading -- "AI-ranked to-dos
   for you & Logan". Alex's had "Tasks" and then a large empty gap.

   The .top .sub rule has been sitting in styles.js the whole time with nothing
   rendering into it. Every screen in the Suite opened with a bare word and a
   hole under it. Fourteen subtitles added, one per screen, kept in one list
   next to the nav so it is obvious when a new screen ships without one.

2. THE ADD CARD WASTED A THIRD OF A SCREEN. It had "Add a task" plus a line of
   explanation above a single text field, on the screen somebody opens to see
   the list. ProyTech's is just the input and the controls in a bare card. The
   placeholder already says what the field is for.

3. THE ROWS WERE NOT CARDS. This was the big one. ProyTech renders each task as
   a .card -- 22px radius, soft shadow. Mine were 12px with a flat border,
   which reads as a table row. 22px and a shadow reads as an object you can act
   on, which is what a task is.

4. THE SCORES WERE BARE GREY TEXT. ProyTech rows carry a coloured owner pill
   ("Garrett" with a dot) and that one element is most of what gives the row
   its rhythm. This install has one agent, so an owner pill would invent a
   distinction that does not exist. The impact/urgency/effort figures get the
   same pill treatment instead -- same rhythm, no fabricated data.

Also: the filter bar now wraps cleanly under 1180px instead of jamming the AI
rank button against the segments.
